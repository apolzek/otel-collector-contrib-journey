2. Interfaces principais

component.Component

- Absolutamente todo componente implementa isso. receiver.Traces, exporter.Logs, extension.Extension .. todos eles sao component.Component
- São marker interfaces. Elas existem para que o core possa evoluir cada uma separadamente no futuro sem quebrar as outras.


```
// go.opentelemetry.io/collector/component
type Component interface {
    // Start é chamado no boot. NÃO deve bloquear: se seu componente tem um
    // loop, suba uma goroutine e retorne. Se Start retorna erro, o Collector
    // aborta o boot inteiro.
    Start(ctx context.Context, host Host) error

    // Shutdown é chamado no encerramento. Deve ser idempotente e não
    // bloquear indefinidamente — respeite o ctx.
    Shutdown(ctx context.Context) error
}
```

---

component.Host — o que o componente pode pedir ao Collector

```
type Host interface {
    GetExtensions() map[ID]Component
}
```
